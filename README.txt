BrowserAssist 标签扫描器

双击程序文件夹中的 BrowserAssistScanner.exe 即可运行。无需安装 Python。

默认 VAM 路径：G:\VAM-1.22.0.8
默认 VAR 路径：G:\AddonPackages
默认标签：del（精确匹配，不区分大小写）

使用方法
1. 设置 VAM 根目录和 VAR 扫描目录。
2. 输入标签，点击“刷新扫描”。勾选“包含匹配”后，del 也会匹配 deluxe。
   标签留空时，列出所有带标签的包。
   “显示隐藏”“显示未找到的包”“显示标记为依赖的包”均默认不勾选，位于结果表格上方。
   三项独立叠加：勾选才包含对应包；例如隐藏的依赖包需要同时勾选显示隐藏和显示依赖。
   切换开关只过滤最近一次完整扫描结果，不重新扫描；扫描始终保留未找到的包记录。
   “隐藏”包括 VAM 和 BrowserAssist 用户隐藏标记；未知状态不视为隐藏。
   筛掉已勾选的行不会清空其勾选或折叠状态，底部数量和删除操作仍包含这些已勾选项。
   三项显示开关只在当前运行内保存，每次启动均不勾选，不受旧设置中的 IncludeMissing 影响。
3. 表格显示包名、提示标记、是否收藏、是否隐藏、完整路径、同级项数。点击列标题可以排序。
   橙色醒目标记“依赖”：VAR 位于依赖目录（含上层依赖目录），建议只做隐藏。
   “有收藏的子文件”：当前 VAR 所在目录的子文件夹内（例如 DP、依赖，含递归子目录）有收藏 VAR。
   当前 VAR 自身、同级收藏 VAR、目录外收藏依赖均不计入，即使 meta.json 声明引用，也不显示此提示。
   两个标记可同时出现；只提示，不阻止勾选、自动勾选或删除，也不自动修改隐藏状态。
   点击行后，下方详情列出具体依赖目录和收藏 VAR 的完整路径，建议先人工移出收藏包。
   同级项数不含目标 VAR 本身，包含所在文件夹的其他文件和子文件夹。
   包名前的 ▶ / ▼ 是展开开关，点击后在目标行下方展开或收起列表。数量列仅显示数量。
   所有目录名称后统一加 Windows 的反斜杠 \，只显示名字，不展开其内容。
   同级 VAR 在“是否收藏”“是否隐藏”列显示是 / 否 / 未知，核对规则与顶层 VAR 相同，
   不受 del 标签和前端过滤限制。文件夹、说明文档等非 VAR 项目显示 —。
   同级状态在扫描时读取并缓存；展开、折叠或过滤不重新读盘，“刷新扫描”更新状态。
   展开列表包含当前 VAR 本身，收藏、隐藏、提示标记和完整路径与其顶层行一致。
   同目录的所有展开列表内容、排序和勾选状态相同；文件的勾选按完整路径共享。
   在任何位置勾选或取消同一个文件，会同步其顶层行及各列表副本，数量和删除目标只计一次。
   缺失文件为 —，读取失败为未知。
   ← 收起当前行所属的同级列表；→ 展开当前顶层行；空格切换当前项勾选，保持当前行焦点。
   行高固定为 32，不支持鼠标拖动调整。较长名字可以通过悬停提示查看完整内容。
4. 每行开头可以勾选实际存在的 VAR。勾选后自动展开同级项，并出现同级项的勾选框。
   智能初始勾选：同目录没有其他 .var，且子目录为依赖目录或不含 VAR 的资料目录时，
   自动勾选全部同级项，以及层级最多的冗余父目录（列表最后一项），包含其下方的中间目录。
   冗余目录候选仍会在出现邻居、目录链接或到达扫描根目录时停止，不包含扫描根目录。
   依赖目录识别依赖、DP、dep、deps、Depend、Depends、Dependent、Dependency、dependencies
   等名称，不区分英文大小写，支持 Tina_Dependencies、KITTY依赖等带前后缀的名称。
   多个同级 VAR（即使其他 VAR 未显示、已标 del 或已勾选），普通子目录内存在 VAR，
   同级内容含链接或核对失败时，仅勾选当前 VAR，其余全部手动选择。
   不根据外观或发型、衣物等文件名自动删除混放依赖；引用关系无法证明其仅供当前包使用。
   初始规则仅在取消后重新勾选 VAR 时执行，不反复覆盖手动调整。
   目录尚未选择时，列表中的顶层 VAR 副本可勾选；目录有选择后，全部同级项显示勾选框。
   允许手动折叠；折叠、排序和结果搜索不会清空勾选，各顶层行的展开开关仍独立。
   取消一个顶层 VAR 不清除同目录其他已选主 VAR 和共享同级项；取消最后一个时清空附加选择。
   同目录的冗余父目录单选也共享；从任一列表取消同级项会同步取消冗余父目录选择。
   勾选只保存在本次运行的内存中，关闭程序后不保留。刷新保留仍存在的已勾选项目。
   同级列表最前面为“冗余父目录”分组，目录以反斜杠 \ 结尾。
   当前 VAR 所在目录是第一候选；如果更上层目录仅包含该目录，则继续逐层加入候选。
   搜索到“VAR扫描目录”停止，不包含扫描目录；扫描范围外的文件没有冗余父目录选项。
   用单选框选择要回收的最高层级，再次点击或按空格可取消；智能规则不符合时默认不选。
   选择冗余父目录会自动勾选全部同级项；取消任意同级项会自动取消冗余父目录选择。
   选择更高层级会包括其下方的中间目录，数量按实际文件和各层目录合计。
   刷新出现新同级项或候选目录不再符合条件时，取消冗余父目录选择，不自动选中新项目。
5. 有勾选时，底部显示数量、“删除选中文件”“标记为隐藏”和“全部取消勾选”。全部取消会清空所有勾选。
   数量按完整路径去重；包括已折叠、被结果搜索隐藏的勾选项。
   “标记为隐藏”只处理明确勾选的 VAR（包括同级列表中的 VAR），同一文件只处理一次。
   忽略文件夹和说明文档，不递归隐藏所选文件夹内部的 VAR；没有勾选 VAR 时按钮不可用。
   为所选包具体版本中的场景、预设、衣物、头发、插件、音频及资产资源创建原生 .hide 标记，
   路径为 VAM\AddonPackagesFilePrefs\作者.包名.版本\包内资源路径.hide；不修改 VAR 文件、
   收藏标记或 BrowserAssist 标签记录，已存在的隐藏标记保持原样。无法读取或无可隐藏资源时报告。
   完成后自动刷新，成功的 VAR 取消勾选；取消最后一个顶层 VAR 时也清空该目录附加选择。
   失败项目保留勾选，可点击“停止”取消后续处理。默认不显示隐藏包，勾选“显示隐藏”可查看。
   VaM / BrowserAssist 已打开时，其自身的资源界面可能需要刷新后才能读取新的磁盘标记。
6. 点击“删除选中文件”将勾选的文件和文件夹移入回收站。选中文件夹包含其所有内容。
   先按可执行文件名称检测 VaM.exe、vambox.exe，路径和版本不影响检测。
   检测到任意一个运行时，显示：检测到VAM正在运行中， 删除速度较慢，是否确认删除？
   确认后使用程序内实现的逐项递归回收：先处理文件和子目录，再回收空目录。
   未检测到运行时，使用 Windows IFileOperation API 批量回收顶层项目，由系统处理文件夹内容。
   两种方式都要求进入回收站，不提供永久删除回退；无法回收、占用或类型改变的项目会报告。
   重叠勾选的父目录和内部项目只处理一次。递归模式保留新出现的文件、非空目录和目录链接。
   文件回收完成后，自下而上检查并回收所选冗余父目录。仅回收空目录；占用、删除失败或
   新出现的文件使目录非空时保留目录，并在结果中报告，不删除新出现的内容。
   回收过程中可点击“停止”；已完成的项目仍在回收站。操作结束后自动刷新列表。
   关闭窗口会先停止当前回收操作，再关闭程序。
7. 在包名或同级 .var 文件名上停留约 0.4 秒，浮窗显示 256×256 缩略图。
   扩展名不区分大小写；目录和其他格式文件不显示缩略图。无法获取时显示“无可用缩略图”。
   使用 Windows 系统缩略图处理器后台读取，并在本次运行中缓存；文件变化时自动重新读取。
   VAR 缩略图依赖系统已注册的 VAR 缩略图处理器；没有对应处理器时可能无法生成缩略图。
   移开鼠标、滚动、刷新、折叠或切到其他窗口时隐藏浮窗，不改变焦点或勾选状态。
   点击完整路径打开资源管理器，并选中 VAR 文件。双击包名、收藏或隐藏列也可打开。
   同级文件或文件夹名称也支持双击，打开其所在文件夹并选中该项目；右键可复制其实际路径。
8. 右键可打开文件夹或复制路径。“结果搜索”在已完成的结果中搜索包名、路径、标签和提示标记。
9. “导出 CSV”导出当前显示、当前排序的六列包数据（含提示标记），使用 UTF-8 BOM，兼容 Excel 中文。
   展开的同级名称不作为包记录导出。同级内容随“刷新扫描”重新读取。
10. 扫描期间可点击“停止”。刷新失败或取消时保留上次完整结果。

读取规则
- 标签来源：VAM\Saves\PluginData\JayJayWon\BrowserAssist\VARResourcesUserData\*.userData。
- 按作者、包名和包内资源路径关联标签。相同包的多个版本分别显示。
- 扫描所选 VAR 目录，并补充 VAM\AddonPackages 及 BrowserAssist\OffloadedVARs。
- 跟随目录链接并解析真实路径，避免重复文件或链接循环。
- 收藏/隐藏为用户标记：包内至少一项存在的资源有 BrowserAssist Active 状态，
  或 VAM\AddonPackagesFilePrefs 下存在 .fav/.hide 标记，显示“是”。
  “是”不表示整个包的全部资源被收藏或隐藏。
- 未找到磁盘文件的包保留为“版本未确认”，状态注明“记录”，不能点击打开。
- 如果 VAR 或标记目录无法读取，无法确认的状态为“未知”，原因显示在“扫描提示”。
- 不读取 VAR 内作者自带标记作为用户收藏/隐藏。插件按标签自动隐藏规则不计入用户标记。
- 收藏子文件核对不受 del 过滤影响，使用相同的 BrowserAssist 实际资源及 VAM .fav 规则。
  只核对当前 VAR 所在目录的子文件夹内的收藏 VAR，包含递归子目录中的文件；同级收藏 VAR 不提示。
  按实际文件位置判断，不依据 meta.json 的外部依赖引用扩大范围；不将当前 VAR 自身算作子文件。
  核对失败的文件在“扫描提示”中列出。
- 扫描和刷新只读取 VAM 和 VAR 数据；点击“删除选中文件”回收所选磁盘项目，
  点击“标记为隐藏”写入 VAM 原生 .hide 标记。不会修改 BrowserAssist 标签记录或收藏标记。
  回收后可能显示为“未找到”的记录。

设置保存在 %LOCALAPPDATA%\BrowserAssistScanner\settings.json。
运行环境：Windows 8 或以上，.NET Framework 4.5 或以上（本机为 4.8）。
重新编译：PowerShell 执行 .\Build.ps1。
验证：PowerShell 执行 .\Test.ps1，扫描、状态和回收测试仅操作新建的临时样本。
测试产物集中在 test-artifacts 下；UI 预览截图和对应 JSON 均放在 test-artifacts\ui-previews。
